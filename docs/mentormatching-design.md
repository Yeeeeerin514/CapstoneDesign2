# 안심알바 — 멘토·멘티 매칭 시스템 


## 1. 한 줄로 말하면

**"임금체불 당해본 선배(멘토)와 지금 당하고 있는 후배(멘티)를, 비슷한 상황끼리 자동으로 짝지어주는 기능"** 이에요.

마치 결혼정보회사가 "이상형 정보 받아서 잘 맞는 사람 소개해주는 것"처럼,
우리는 "피해 상황 정보를 받아서 잘 맞는 멘토를 소개해주는" 거예요.

---

## 2. 왜 만드는 거예요?

지금 안심알바 앱은 이런 걸 해줘요:

-  나쁜 알바 공고를 AI가 미리 걸러줌
-  계약서가 이상한지 분석해줌
-  임금체불 당하면 신고서 초안을 만들어줌

근데 막상 신고하러 갈 때가 되면 사용자가 이런 걸 궁금해해요:

> "노동청 가면 진짜 어떻게 진행돼요? 분위기 어때요?"
> "사장이 잠수 탔는데 어떻게 잡았어요?"
> "저랑 똑같은 상황이었던 분 얘기 듣고 싶어요…"

이런 건 AI가 일반론밖에 못 줘요. **실제 겪어본 사람의 경험담**이 훨씬 와닿죠.
그래서 "해결해본 사람"과 "지금 겪는 사람"을 연결해주려는 거예요.

---

## 3. 어떤 정보로 짝을 지어요?

사용자가 가입할 때 이런 항목을 골라요 (전부 객관식이라 쓰기 쉬움):

| 항목 | 예시 |
|------|------|
| 어떤 피해? | 임금체불 / 주휴수당 / 퇴직금 / 부당해고 … |
| 어디서? | 편의점 / 배달 / 식당 / 사무직 … |
| 사업장 크기? | 5인 미만 / 5~30인 / 30인 이상 |
| 얼마나 떼였어요? | 10만원 이하 / 50만원 이하 / … |
| 어떻게 해결했어요? (멘토만) | 노동청 진정 / 소송 / 합의 … |
| 어디 사세요? | 서울 / 경기 / … |

> 💡 자유서술(긴 글)은 안 받아요. 객관식만으로도 충분히 비슷한 사람을 찾을 수 있고, 사용자도 편해요.

---

## 4. 매칭은 어떻게 이루어져요? (4단계)

### 🎯 1단계 — 명백히 안 맞는 멘토는 거름
"피해유형이 단 1개도 안 겹치는 멘토"는 처음부터 후보에서 뺍니다.
(임금체불 당한 사람한테 부당해고만 해본 멘토를 추천하면 도움이 안 되니까요.)

### 📏 2단계 — 얼마나 비슷한지 점수 매김

"항목별로 얼마나 닮았나"를 점수로 계산해요.

```
예시) 멘티 A씨와 멘토 김씨의 닮은 정도

✅ 피해유형 (주휴수당)  → 똑같음 → 점수 ↑↑
✅ 사업장 크기 (5인 미만) → 똑같음 → 점수 ↑↑
✅ 업종 (편의점)          → 똑같음 → 점수 ↑
❌ 지역 (서울 vs 부산)    → 다름   → 점수 ↓
```

**중요한 항목엔 더 큰 가중치**를 줘요.
예를 들어 "사업장이 5인 미만이냐 아니냐"는 법 적용이 완전히 달라져서 매우 중요해요.
반면 "연령대"는 비슷하면 좋지만 결정적이진 않죠.

### 💑 3단계 — 안정적인 짝짓기 (Gale-Shapley)

여기가 좀 신박한 부분이에요.

만약 단순히 "점수 높은 멘토 3명"만 추천하면 어떻게 될까요?
→ **인기 멘토 한 명한테 멘티 100명이 몰림** → 멘토 지쳐서 그만둠 → 망함 😱

그래서 **결혼정보회사도 쓰는 안정매칭 알고리즘**을 써요.
(참고로 이거 만든 사람들 노벨 경제학상 받았어요. 2012년.)

작동 방식:
1. 멘티들이 각자 마음에 드는 멘토에게 "신청"
2. 멘토는 자기 정원(예: 3명) 안에서 가장 잘 맞는 멘티만 임시 수락
3. 떨어진 멘티는 다음 후보에게 다시 신청
4. 다 짝이 맞을 때까지 반복

→ 결과: **모두가 "이 정도면 만족"하는 짝**이 만들어짐. 한쪽에 쏠리지 않음.

### 🧠 4단계 — 점점 똑똑해지기 (Thompson Sampling)

처음엔 우리도 "어떤 항목이 매칭에 제일 중요한지" 잘 몰라요.
일단 추측해서 가중치를 줬지만, 사실 틀릴 수도 있죠.

그래서 **사용자 피드백으로 가중치를 조금씩 조정**해요.

```
멘티가 "이 멘토 도움 많이 됐어요 ⭐⭐⭐⭐⭐" 라고 평가하면
→ 그 매칭에서 영향이 컸던 항목의 가중치를 살짝 ↑

멘티가 "별로였어요 ⭐" 라고 하면
→ 그 항목의 가중치를 살짝 ↓
```

이걸 자동으로, 수학적으로 균형 있게 해주는 게 **Thompson Sampling**이에요.
*비유하자면*: 음식 배달 앱이 처음엔 아무거나 추천하다가, 사용자가 별점을 매기면 매길수록 점점 취향에 맞게 추천해주는 거랑 비슷해요.

데이터가 10건만 쌓여도 작동하기 시작해서, 100건쯤 되면 꽤 정확해져요.

## 5. 사용자한텐 어떻게 보여요?

멘티가 매칭을 요청하면 이런 카드가 떠요:

```
┌─────────────────────────────────────┐
│  🥇 추천 멘토 #1                     │
│  닉네임: 알바마스터                  │
│                                     │
│  💡 이 멘토를 추천한 이유            │
│   ✓ 같은 피해유형 (주휴수당)         │
│   ✓ 같은 사업장 규모 (5인 미만)      │
│   ✓ 노동청 진정 해결 경험            │
│                                     │
│  [ 대화 신청하기 ]                  │
└─────────────────────────────────────┘
```

**"왜 이 사람을 추천했는지"를 항상 보여줘요.** 그래야 사용자가 신뢰하고 클릭하니까요.
